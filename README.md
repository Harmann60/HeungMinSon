# ⚽ **Heung-Min Son Website** 🇰🇷

A modern, responsive, and interactive fan website dedicated to **Heung-Min Son**, the South Korean football legend and Tottenham Hotspur captain. Now plays for LAFC in MLS.  
Built with ❤️ using **React**, **Vite**, and **Tailwind CSS**.

---

## 🌍 **Vision**

There are official websites for players like **Messi** and **Ronaldo**, but none that truly capture **Heung-Min Son’s** story, energy, and humility.
This project aims to **fill that gap** — creating a dedicated fan website that celebrates his journey, achievements, and the values that make him one of football’s most admired players. ⚽🔥

---

## 🌟 **About the Project**

This website is a personal tribute to Heung-Min Son — highlighting his rise from his early days in Korea to becoming Tottenham’s captain and a symbol of consistency and leadership.

The site showcases:

* 🧠 His biography and football journey
* 📊 Career stats and achievements
* 🏆 Memorable goals and highlights
* 🎨 A clean, responsive design

## 💻 **How to Run Locally**

```bash
# Clone the repository
git clone https://github.com/your-username/son-website.git

# Navigate into the folder
cd son-website

# Install dependencies
npm install

# Start the development server
npm run dev
```
